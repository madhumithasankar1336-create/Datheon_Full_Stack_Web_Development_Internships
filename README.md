# 🚀 Datheon Full Stack Web Development Internship

This repository contains three projects completed as part of my Datheon Full Stack Web Development Internship.

## 📌 Task 1: Personal Developer Portfolio

A responsive portfolio website to showcase my skills, projects, and resume.

**Features:**

* Dark/Light Mode
* Responsive Design
* Project Showcase
* Skills and Resume Sections

## 📌 Task 2: Dynamic Task Manager

A productivity application for managing daily tasks.

**Features:**

* CRUD Operations
* Task Search and Filtering
* Drag-and-Drop
* LocalStorage Integration

## 🌸 Task 3: PINK BLOOM E-Commerce Website

A premium pink-themed shopping website with interactive shopping features.

**Features:**

* Live Product Data using Fake Store API
* Product Search, Filtering, and Sorting
* Shopping Cart with Quantity Controls
* Cart Data Persistence
* Price Calculation and Simulated Checkout

## 🛠️ Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript
* Fetch API
* LocalStorage
* Fake Store API

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Run `index.html` using a local development server.
4. Explore the website features in your browser.

**For PINK BLOOM:** If JavaScript ES modules are used, start a local server:

```bash
python -m http.server 5500
```

Then open `http://localhost:5500` in your browser.
